# Тест Кейс ID: TC-005	
## Проект: 
Лендинг «Графический дизайнер»	
## Дата создания:
22.10.2026	
## Результат проверки:
Провален
			
## Заголовок: 
Проверка чекбокса на обработку персональных данных в форме заявки на консультацию по оплате	
## Описание: 
Проверить текст рядом с чекбоксом, обязательность чекбокса, его кликабельность и переход по ссылке	
## Предусловия:
1. Открыть браузер на весь экран;
2. Открыть страницу лендинга "Графический дизайнер" - https://sky.pro/courses/design/graf-designer_homework
3. Перейти к блоку "Стоимость и варианты оплаты курса";
4. Найти форму заявки на консультацию по оплате;
5. Заполнить поля "Имя", "Телефон" и "Эл.почта" валидными данными;
