# Тест Кейс ID: TC-004	
## Проект: 
Лендинг «Графический дизайнер»	
## Дата создания:
22.10.2026	
## Результат проверки:
Провален	
			
## Заголовок: 
Проверка поля ввода "Имя" в форме заявки на консультацию по оплате	
## Описание: 
Проверить наличие подсказки, валидации и ограничения по вводу символов	
## Предусловия:
1. Открыть браузер на весь экран;
2. Открыть страницу лендинга "Графический дизайнер" - https://sky.pro/courses/design/graf-designer_homework
3. Перейти к блоку "Стоимость и варианты оплаты курса";
4. Найти форму заявки на консультацию по оплате.

!!! Для шагов 2-8 выполнить: 
- Заполнить поля "Телефон" и "Эл.почта" валидными данными;
- Отметить чекбокс согласия на обработку персональных данных;
- После заполнения поля "Имя" нажать кнопку ""Записаться на курс"".
